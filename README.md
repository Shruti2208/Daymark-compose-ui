# Daymark

Daymark is a sample Android life dashboard built with Kotlin, Jetpack Compose, and Material 3. It brings daily habits, weekly progress, places, and journal entries together in one app.

## Run locally

Open the repository in Android Studio, sync Gradle, and run the `app` module on a device or emulator running Android 7.0 (API 24) or later. The project compiles against Android SDK 37.1.

To build a debug APK from the terminal, run `./gradlew :app:assembleDebug`.
